# Эмулятор UNIX-оболочки

## Описание

Учебный проект по дисциплине
«Конфигурационное управление».

Вариант №9.

Графический эмулятор UNIX-подобной оболочки.

Язык: Python 3.
Графический интерфейс: Tkinter.

## Реализованные этапы

### Этап 1. REPL

- Графический интерфейс.
- Заголовок с именем пользователя и компьютера.
- Разбор команд и аргументов.
- Раскрытие переменных окружения.
- Обработка ошибок.
- Команда exit.

### Этап 2. Конфигурация

- Параметры --vfs, --prompt, --startup.
- Отладочный вывод настроек.
- Выполнение стартовых скриптов.
- Продолжение работы после ошибок.
- BAT-сценарии для Windows.

### Этап 3. VFS

- Загрузка директории в оперативную память.
- Сохранение файлов и каталогов.
- Поддержка вложенных каталогов.
- Поддержка бинарного содержимого.
- Обработка ошибок загрузки.
- Сохранение исходных файлов без изменений.

### Этап 4. Основные команды

- ls — просмотр содержимого VFS.
- cd — переход между каталогами VFS.
- tac — обратный вывод строк файла.
- whoami — имя пользователя реальной ОС.
- Сохранение текущего каталога между командами.
- Поддержка абсолютных и относительных путей.
- Проверка аргументов и обработка ошибок.

## Команды

### ls [путь]

Без аргументов показывает текущий каталог.

С аргументом показывает указанный каталог
или имя существующего файла.

Каталоги отображаются с символом / в конце.

### cd [путь]

Изменяет текущий каталог VFS.

Без аргументов переходит в корень.

Примеры:

cd documents
cd ..
cd /

### tac файл

Выводит строки текстового файла
в обратном порядке.

Поддерживаются текстовые файлы UTF-8.

### whoami

Показывает имя пользователя реальной ОС.

Не принимает аргументы.

### exit

Завершает работу эмулятора.

Не принимает аргументы.

## Конфигурация

### --vfs

Путь к директории, используемой как VFS.

### --prompt

Пользовательское приглашение к вводу.

Значение по умолчанию: "$ ".

### --startup

Путь к текстовому стартовому скрипту.

Команды выполняются последовательно.
Ошибки не останавливают выполнение.
Команда exit завершает работу.

## Переменные окружения

Поддерживаются переменные:

- $USERNAME
- $HOME
- ${USERNAME}

Значения берутся из реальной ОС.

## Виртуальная файловая система

VFS загружается из директории на диске.

Файлы и каталоги хранятся в памяти.

Команды ls, cd и tac работают с VFS.

Исходные файлы не изменяются.

Символические ссылки не поддерживаются.

## Сборка и запуск

Требуется Python 3.10 или новее
с поддержкой Tkinter.

Отдельная сборка не требуется.

Запуск в Windows:

run.bat

Запуск с VFS:

run.bat --vfs vfs_examples/deep

Запуск с параметрами:

run.bat --vfs vfs_examples/deep --prompt "unix$ " --startup scripts/stage4_demo.txt

Демонстрационный BAT-сценарий:

scripts/launch_stage4.bat

## Примеры работы

Команда:

ls

Результат для VFS deep:

level1/
root.txt

Команда:

cd level1

Результат:

Текущий каталог становится /level1.

Команда:

tac info.txt

Результат:

First directory level.

Команда:

whoami

Результат:

Имя пользователя операционной системы.

Команда:

exit

Результат:

Графическое окно закрывается.

## Ограничения текущей версии

без дополнительных UNIX-флагов.

Команда tac предназначена для файлов UTF-8.

Команды chown и cp будут реализованы
на следующем этапе.

# Эмулятор UNIX-оболочки — вариант №9

Учебный проект по дисциплине «Конфигурационное управление».
Python 3.10+ и Tkinter. GUI запускается из `src.main`.

## Реализованные этапы

1. REPL: GUI, парсер, переменные окружения, `exit`.
2. Конфигурация: `--vfs`, `--prompt`, `--startup`, стартовые скрипты.
3. VFS: загрузка каталога в память, сохранение файлов и папок.
4. Команды `ls`, `cd`, `tac`, `whoami`.
5. Команды `cp`, `chown`, отображение владельцев через `ls -l`.

## Запуск

Из корня проекта в Windows:

```bat
run.bat --vfs "vfs_examples/deep" --prompt "unix$ " --startup "scripts/stage5_demo.txt"
```

Или запустите `scripts/launch_stage5.bat`.

## Команды

- `ls [путь]` — список объектов текущего или указанного каталога.
- `ls -l [путь]` — список с виртуальными владельцами.
- `cd [путь]` — сменить виртуальный каталог; без аргументов — `/`.
- `tac файл` — строки UTF-8 файла в обратном порядке.
- `whoami` — имя пользователя реальной ОС.
- `cp источник назначение` — копировать файл, при совпадении имени перезаписать виртуальную копию.
- `cp -r каталог назначение` — рекурсивно копировать каталог; также поддерживается `-R`.
- `chown владелец путь` — изменить виртуального владельца объекта.
- `chown -R владелец каталог` — изменить владельца каталога и всех его потомков; также поддерживается `-r`.
- `exit` — завершить работу.

Пути внутри VFS — UNIX-подобные, абсолютные или относительные.
Владельцы являются метаданными эмулятора, а не правами Windows.
Скопированные объекты сохраняют виртуального владельца источника.

## Гарантии и ограничения

Исходные файлы VFS только читаются при загрузке. Все копирования и
изменения владельцев происходят исключительно в памяти. При новом
запуске изменения не сохраняются. Символические ссылки запрещены.

Команды поддерживают учебное подмножество синтаксиса UNIX. Ключи,
кроме перечисленных, не реализованы. `tac` читает UTF-8.

## Структура

- `src/main.py` — графическое окно.
- `src/config.py` — параметры запуска.
- `src/shell.py` — команды и состояние оболочки.
- `src/startup.py` — стартовые скрипты.
- `src/vfs.py` — виртуальная файловая система и операции в памяти.
- `tests/` — автоматические тесты `unittest`.
- `scripts/` — демонстрационные файлы и BAT-сценарии.
- `vfs_examples/` — примеры исходных директорий.
- `run.bat` — запуск из Windows.

## Тестирование

Запуск из корня проекта:

```bat
python -m unittest discover -s tests -v
```

После добавления `tests/test_stage5.py` предусмотрено 70 тестов:
50 предыдущих и 20 новых.

Проверка этапа 5: `scripts/stage5_demo.txt` демонстрирует копирование,
смену владельцев, рекурсивные операции и обработку ошибок.

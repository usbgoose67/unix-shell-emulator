# Эмулятор UNIX-оболочки

## Общее описание

Учебный проект по дисциплине
«Конфигурационное управление».

Вариант №9.

Графический эмулятор командной оболочки
UNIX-подобной операционной системы.

Язык реализации: Python 3.
Графический интерфейс: Tkinter.

## Реализованные этапы

### Этап 1. REPL

- Графическое окно для ввода команд.
- Заголовок с именем пользователя и компьютера.
- Разбор команд и аргументов.
- Раскрытие переменных окружения.
- Команды-заглушки ls и cd.
- Команда exit.
- Обработка ошибок ввода.

### Этап 2. Конфигурация

- Параметры запуска через командную строку.
- Отладочный вывод настроек.
- Пользовательское приглашение к вводу.
- Выполнение стартовых скриптов.
- Пропуск ошибочных команд в скрипте.
- Отображение ввода и вывода команд.
- Несколько BAT-скриптов для Windows.

## Поддерживаемые команды

### ls

Выводит имя команды и список аргументов.

### cd

Выводит имя команды и список аргументов.

### exit

Завершает работу приложения.

На текущем этапе ls и cd являются заглушками.

## Параметры запуска

### --vfs

Путь к физическому расположению VFS.

Пока параметр сохраняется и выводится.
Загрузка VFS будет реализована на этапе 3.

### --prompt

Пользовательское приглашение к вводу.

Значение по умолчанию: "$ ".

### --startup

Путь к текстовому файлу стартового скрипта.

Команды выполняются последовательно.
Ошибочные команды не останавливают скрипт.
Команда exit завершает выполнение.

## Переменные окружения

Поддерживаются переменные вида:

- $USERNAME
- $HOME
- ${USERNAME}

Значения берутся из реальной ОС.

## Структура проекта

- src/main.py — графический интерфейс.
- src/shell.py — обработка команд.
- src/config.py — параметры запуска.
- src/startup.py — выполнение скриптов.
- tests — автоматические тесты.
- scripts — демонстрационные сценарии.
- run.bat — основной скрипт запуска.
- .gitignore — исключения для Git.

## Сборка и запуск

Требуется Python 3 с поддержкой Tkinter.

Отдельная сборка не требуется.

Для запуска в Windows используется run.bat.

Запуск с параметрами:

run.bat --vfs example_vfs --prompt "test$ " --startup scripts/demo.txt

Демонстрационные сценарии:

- scripts/launch_default.bat
- scripts/launch_custom.bat
- scripts/launch_errors.bat

## Тестирование

Используется стандартная библиотека unittest.

Тесты расположены в папке tests.

В PyCharm можно запустить все тесты
через конфигурацию Unittests.

## Примеры использования

Команда:

ls

Результат:

ls: аргументы: []

Команда:

cd documents

Результат:

cd: аргументы: ['documents']

Команда:

unknown

Результат:

Ошибка: неизвестная команда 'unknown'

Команда:

exit

Результат:

Окно приложения закрывается.

# Эмулятор UNIX-оболочки

## Общее описание

Учебный проект по дисциплине
«Конфигурационное управление».

Вариант №9.

Графический эмулятор командной оболочки
UNIX-подобной операционной системы.

Язык: Python 3.
Интерфейс: Tkinter.

## Реализованные этапы

### Этап 1. REPL

- Графический интерфейс.
- Заголовок из данных реальной ОС.
- Парсер команд.
- Раскрытие переменных окружения.
- Команды ls, cd, exit.
- Обработка ошибок.

### Этап 2. Конфигурация

- Параметры --vfs, --prompt, --startup.
- Отладочный вывод параметров.
- Стартовые скрипты.
- Последовательное выполнение команд.
- Пропуск ошибочных команд.

### Этап 3. VFS

- Загрузка VFS из директории на диске.
- Хранение структуры каталогов в памяти.
- Хранение содержимого файлов в памяти.
- Поддержка вложенных и пустых каталогов.
- Поддержка бинарного содержимого файлов.
- Отображение количества файлов и каталогов.
- Обработка ошибок загрузки.
- Три примера структуры VFS.
- BAT-сценарии тестирования VFS.

Исходные данные VFS не изменяются.

Символические ссылки не поддерживаются.

## Команды эмулятора

### ls

Показывает имя команды и её аргументы.

### cd

Показывает имя команды и её аргументы.

### exit

Завершает работу приложения.

На третьем этапе ls и cd остаются заглушками.
Их логика будет реализована на этапе 4.

## Конфигурация

### --vfs

Путь к исходной директории VFS.

Если параметр указан, директория
загружается в оперативную память.

### --prompt

Пользовательское приглашение к вводу.

По умолчанию используется "$ ".

### --startup

Путь к стартовому текстовому скрипту.

Команды выполняются последовательно.
Ошибки не прерывают выполнение.
Команда exit завершает работу.

## Переменные окружения

Поддерживаются переменные вида:

- $USERNAME
- $HOME
- ${USERNAME}

Значения берутся из реальной ОС.

## Структура проекта

- src/main.py — графический интерфейс.
- src/shell.py — обработка команд.
- src/config.py — конфигурация.
- src/startup.py — стартовые скрипты.
- src/vfs.py — виртуальная файловая система.
- tests — автоматические тесты.
- scripts — сценарии запуска.
- vfs_examples — примеры исходных директорий.
- run.bat — запуск приложения.
- .gitignore — исключения Git.

## Сборка и запуск

Требуется Python 3 с поддержкой Tkinter.

Отдельная сборка не требуется.

Основной запуск в Windows:

run.bat

Запуск с VFS:

run.bat --vfs vfs_examples/minimal

Запуск с тремя параметрами:

run.bat --vfs vfs_examples/deep --prompt "test$ " --startup scripts/vfs_demo.txt

## Примеры VFS

### Минимальная

vfs_examples/minimal

Один файл в корневом каталоге.

### Несколько файлов

vfs_examples/multiple

Три файла и вложенный каталог.

### Глубокая структура

vfs_examples/deep

Три уровня вложенных каталогов.

## Проверка BAT-сценариев

- scripts/launch_vfs_minimal.bat
- scripts/launch_vfs_multiple.bat
- scripts/launch_vfs_deep.bat
- scripts/launch_vfs_missing.bat

Сценарии запускают эмулятор с различными
параметрами и источниками VFS.

## Тестирование

Используется стандартная библиотека unittest.

Тесты находятся в папке tests.

Для запуска всех тестов в PyCharm
используется конфигурация Unittests
с целевой директорией tests.

После этапа 3 предусмотрено 32 теста.

## Примеры команд

Ввод:

ls documents

Результат:

ls: аргументы: ['documents']

Ввод:

cd folder

Результат:

cd: аргументы: ['folder']

Ввод:

unknown

Результат:

Ошибка: неизвестная команда 'unknown'

Ввод:

exit

Результат:

Окно приложения закрывается.

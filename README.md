# Эмулятор UNIX-оболочки

## Общее описание

Учебный проект по дисциплине
«Конфигурационное управление».

Вариант №9.

Проект представляет собой графический эмулятор
командной оболочки UNIX-подобной операционной системы.

Язык реализации: Python 3.
Графический интерфейс: Tkinter.

## Этап 1. REPL

Реализованы:

- Графическое окно для интерактивного ввода команд.
- Заголовок с именем пользователя и компьютера.
- Разбор команд и аргументов.
- Раскрытие переменных окружения реальной ОС.
- Команды-заглушки ls и cd.
- Команда exit для завершения работы.
- Обработка неизвестных команд и ошибок ввода.
- Автоматические тесты.

## Команды

### ls

Выводит имя команды и переданные аргументы.
На первом этапе не обращается к файловой системе.

### cd

Выводит имя команды и переданные аргументы.
На первом этапе не изменяет текущий каталог.

### exit

Завершает работу графического приложения.
Не принимает аргументы.

## Переменные окружения

Поддерживается раскрытие переменных окружения.

Примеры:

- $USERNAME
- $HOME
- ${USERNAME}

Значения берутся из реальной операционной системы.

## Структура проекта

- src/main.py — графический интерфейс.
- src/shell.py — парсер и обработчик команд.
- tests/test_shell.py — автоматические тесты.
- run.bat — скрипт запуска для Windows.
- .gitignore — исключения для Git.

## Сборка и запуск

Необходим Python 3 с поддержкой Tkinter.

Отдельная сборка не требуется.

Запуск в Windows:

run.bat

Также приложение можно запустить в PyCharm,
используя модуль src.main.

## Тестирование

Для тестирования используется unittest.

В PyCharm нужно запустить тесты
из файла tests/test_shell.py.

## Примеры использования

Ввод:

ls

Результат:

ls: аргументы: []

Ввод:

cd documents

Результат:

cd: аргументы: ['documents']

Ввод:

unknown

Результат:

Ошибка: неизвестная команда 'unknown'

Ввод:

exit

Результат:

Окно приложения закрывается.

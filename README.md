
# Эмулятор UNIX-оболочки

## Общее описание

Учебный проект по дисциплине
«Конфигурационное управление».

Вариант №9.

Цель проекта — разработать графический эмулятор
командной оболочки UNIX-подобной операционной системы.

Язык программирования: Python 3.

## Функции и настройки

Проект разрабатывается в пять этапов.

1. REPL: графический интерфейс, команды ls, cd, exit
   и раскрытие переменных окружения.
2. Конфигурация: параметры запуска и стартовые скрипты.
3. VFS: виртуальная файловая система в памяти.
4. Основные команды: ls, cd, tac, whoami.
5. Дополнительные команды: chown, cp.

На текущий момент подготовлена структура проекта.
Функциональность будет добавляться поэтапно.

## Структура проекта

- src — исходный код приложения.
- tests — автоматические тесты.
- run.bat — скрипт запуска для Windows.
- .gitignore — исключения для Git.

## Сборка и запуск

Проект использует Python 3.

Отдельная сборка не требуется.

Для запуска в Windows используется файл run.bat.

До завершения первого этапа скрипт запуска
выводит сообщение о подготовке приложения.

## Тестирование

Автоматические тесты будут добавлены
в ходе выполнения первого этапа.

Тестирование будет выполняться через PyCharm
с использованием библиотеки unittest.

## Примеры использования

После реализации первого этапа можно будет
вводить команды:

- ls
- cd documents
- exit

Дополнительные примеры будут добавлены
по мере реализации остальных этапов.
